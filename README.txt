This is a system for a Virtual Table Top Role Playing Game (VTTRPG) based on Shin Megami Tensei (SMT)

The system is bootstrapped from TheRiseOfTheNewWorld.html where the majority of the game can be played. 

There are 4 sections, Sheet, Demons, Gear, and Edit. 

The sheet which is where the game is primarily played. It contains the demon's stats, skills, abilities, notes, effect
Demons is where you can quickly swap between different demons
Gear is where you can equip your demons with different items you've obtained, add, edit, and delete eqiupment, etc
Edit is used to edit the demon's properties

There is always a log to the right which is where you can use commands to play the game, such as rolling dice
